# Crypto Monitor

Бот для мониторинга цен криптовалют на бирже **Bybit** с отправкой уведомлений в **Telegram** при изменении цены на заданный процент.

## Возможности

- Мониторинг любой торговой пары Bybit (BTCUSDT, ETHUSDT и т.д.)
- Уведомления в Telegram при изменении цены на заданный порог (в процентах)
- Автоматический сброс базовой цены после каждого оповещения — исключает повторные уведомления
- Логирование в файл `app.log` и консоль
- Запуск через Docker / Docker Compose

## Как это работает

1. При запуске фиксируется **базовая цена** выбранной торговой пары.
2. Каждые **7 секунд** запрашивается текущая цена и вычисляется процент изменения относительно базы.
3. Если изменение превышает порог `ALERT_PERCENT`:
   - В Telegram отправляется уведомление с текущей ценой и процентом изменения.
   - Базовая цена сбрасывается на текущую.
4. Цикл повторяется бесконечно.

## Требования

- Python 3.11+
- Telegram Bot Token (получить у [@BotFather](https://t.me/botfather))
- ID чата Telegram (можно узнать через [@userinfobot](https://t.me/userinfobot))
- Docker (опционально, для контейнеризированного запуска)

## Запуск тестов

```bash
pip install pytest pytest-asyncio aiohttp pybit python-dotenv
python -m pytest tests/ -v
```

Все внешние вызовы (Bybit, Telegram) в тестах мокаются — реальные запросы в сеть не выполняются, токен и чат в `.env` для тестов не нужны.
